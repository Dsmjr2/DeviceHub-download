# Carry a settings file key by key when it mixes kinds

A file that holds controls and graphics together is carried key by key, never copied whole, so "graphics off" really leaves the other PC's graphics alone.

**What happened:** THE FINALS' option save was copied whole and brought the PC's resolution, window mode and DLSS to the laptop with graphics switched off.
