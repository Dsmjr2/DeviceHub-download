# Start DeviceHub with flags from PowerShell

Git Bash turns an argument like `/background` into a file path. Start DeviceHub.vbs with its flags from PowerShell or explorer.exe.

**What happened:** Restarts from Git Bash opened a new DeviceHub window each time (six extra windows, about 440 MB).
